9.14-9.20周报

一.本周学习目标：熟悉搜索引擎高级检索语法，尝试部署 DeepSeek Harness 这类 AI Agent 工具。已完成：
  1. 学习 Google、Bing 高级搜索语法，方便快速筛选技术资料；
  2. 安装了npx @deepseek-ai/dsh web，准备配置 AI Agent，了解了 token 相关基础概念；
    后续计划：稳定 token 来源，尝试用 Agent 辅助 Web 安全学习、环境配置、整理复习资料，借助 AI 工具提升学习效率。

二.本周学习目标：本周完成 Burp Suite 的安装配置：
  • 已能够使用 Proxy 模块抓取浏览器网络请求
  • 掌握 HTTP History 查看请求记录、Repeater 重放请求、Intruder 载荷爆破等基础功能操作
  • 同时学习 Markdown 基础语法，借助 Typora/Obsidian 整理学习笔记，沉淀 Web 安全与工具使用相关知识。

例如：Moectf中的MoeCatchTheFrogs题：

  1. 首先阅读前端 JS 源码，寻找后端接口；使用 Burp Suite 代理抓包，在请求 Cookie 中发现frog_session字段。
  2. 对该 Cookie 进行 Base64 解码，读取载荷内容{“frogs”:[0,1,2,3,4,5,6,7]}，判断这是 Flask 框架由 itsdangerous 生成的签名 Session Cookie。
  3. 使用flask-unsign工具，搭配弱口令词表爆破 Flask 的SECRET_KEY，成功得到密钥qwe123456。
  4. 使用获取到的密钥，重新签名构造新 Cookie，修改载荷为{“frogs”:[0,1,2,3,4,5,6,7,8]}。
  5. 在 Burp Suite 的 Repeater 模块中，替换请求里的frog_sessionCookie，访问GET /api/claim接口，成功获取 flag。
    通过本题练习，掌握了 Flask 签名 Cookie 的原理、爆破密钥与伪造 Session 的方法，巩固 Burp 抓包、修改请求重放的实操能力。
三.简单学习HTTP协议：（我有点忘记了好像是moectf2025年也有一道改cookie,referer的题已经会做了，但是找不到了，只能用一道类似的题来代替了😇）
  • 了解GET&POST请求的主要作用与区别
  • 了解常⻅请求头（User-Agent，Cookie，Referer等）的作用和鉴权相关的字段（cookie，jwt，session）
  • 了解常⻅的状态码的含义（200，302，403，5xx等）

例如：完成 BUUCTF [极客大挑战 2019] BuyFlag Web 实操：

  1. 审计靶机前端 HTML 页面，从导航栏找到pay.php页面入口，查看页面注释获取后端 PHP 代码提示；
  2. 使用 Burp Proxy 抓包，观察请求头 Cookie，发现user=0作为身份鉴权字段；
  3. 在 Burp Repeater 修改数据包：将 Cookie 的user=0改为user=1，同时把 GET 请求改为 POST 请求，构造 POST 参数password=404a&money=1e9；
  4. 重放数据包，服务器返回 200 状态码，成功获取 flag。
    • 学习收获：理解 GET/POST 请求差异，掌握 Cookie 身份鉴权原理，熟悉 HTTP 请求头、200/403 状态码含义，熟练 BP 抓包改包操作。

四.简单了解前端三件套（HTML，JavaScript，CSS）：
  • HTML 是网页骨架，搭建页面元素与文档结构；（调节段落，标题什么的）
  • CSS 负责页面样式美化，控制布局、颜色、字体等视觉效果；（页面的渲染）
  • JavaScript 实现网页动态交互，响应用户操作，动态修改页面内容。（编程的内容）

这个只是我的一个简单的理解，CSDN的博客也观看学习其中的内容了

五.熟悉使用F12之后的浏览器原生的devtools：
  • Elements 面板：查看、临时修改 HTML 结构与 CSS 样式，可以实时调整页面元素的布局、颜色、边距，快速预览样式修改效果，方便定位样式错乱问题。（还并没有遇到用面板的题，后面会争取有更多的了解）
  • Console 控制台：执行 JavaScript 代码，查看代码报错信息、打印日志，用来调试 JS 逻辑，定位脚本运行异常。（可以将一些所写的JavaScript代码直接放入控制台中来解决一些问题）
  • Network 网络面板：查看页面发起的所有网络请求，包括请求参数、响应内容、请求状态码、加载耗时，可查看接口数据，排查资源加载失败、请求异常等问题。（网络中如果一直弹一个查询字符串，那我们可以将这个查询字符串接到URL后，有可能是这道题的突破口）
  • 其他基础功能：可查看页面资源、性能加载情况，辅助分析页面加载速度。
